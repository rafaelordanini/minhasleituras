LEITURA — PROTÓTIPO DE INTERFACE

Abra index.html em um navegador moderno.

Recursos demonstrados:
- Layout editorial em três áreas: biblioteca, leitor e painel de notas.
- Upload local de TXT, MD e HTML.
- Importação de links (depende de CORS do site; produção deve usar backend).
- Seleção de texto com destaque e criação de nota.
- Busca e filtros de notas por etiquetas.
- Exportação das notas para Markdown (clique em “Notas & destaques”).
- Leitura em voz alta via SpeechSynthesis do navegador.
- Modo foco.

Observações:
- Este é um protótipo front-end sem persistência em banco.
- PDF/EPUB exigem integração posterior (PDF.js/EPUB.js ou backend de extração).
